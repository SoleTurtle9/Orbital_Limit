**Orbital Limit**

Orbital Limit — дипломный проект, разрабатываемый на Unity.

**О проекте**

Orbital Limit — 2D-игра в космическом сеттинге, в которой игрок управляет космическим кораблём и исследует игровое пространство.

Проект создаётся в рамках дипломной работы.

**Основные возможности**

На данный момент реализовано:

* Управление космическим кораблём
* Управление с клавиатуры
* Поддержка клавиш WASD
* Поддержка клавиш-стрелок

Проект находится в активной разработке, поэтому список возможностей будет дополняться.

**Управление**

Действие	Клавиши
Движение вверх	W / ↑
Движение вниз	S / ↓
Движение влево	A / ←
Движение вправо	D / →

**Технологии**

* Unity
* C#
* Universal Render Pipeline (URP)
* Unity Input System

**Платформа**

Целевая платформа

Windows

macOS / Apple Silicon

Проект разрабатывается на MacBook с процессором Apple Silicon, а целевая платформа игры — Windows.
