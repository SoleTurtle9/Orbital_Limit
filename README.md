Orbital Limit

Orbital Limit — дипломный проект, разрабатываемый на Unity.

О проекте

Orbital Limit — 2D-игра в космическом сеттинге, в которой игрок управляет космическим кораблём и исследует игровое пространство.

Проект создаётся в рамках дипломной работы.

Основные возможности

На данный момент проект находится на этапе разработки.

Планируемые возможности:

* Управление космическим кораблём
* Передвижение по игровому пространству
* Космические объекты
* Игровые задания
* Система взаимодействия с объектами
* Игровой интерфейс

Список возможностей будет дополняться по мере разработки.

Технологии

* Unity
* C#
* Universal Render Pipeline (URP)
* Unity Input System

Платформа

Целевая платформа

Среда разработки

macOS / Apple Silicon
