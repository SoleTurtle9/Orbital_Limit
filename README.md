# 🚀 Orbital Limit

**Orbital Limit** — небольшая 2D космическая игра, разработанная на Unity.

Игрок управляет космическим кораблём, уклоняется от астероидов и набирает очки.

## 🎮 Текущая версия

**v0.1.0 — First Playable Build**

Проект находится на ранней стадии разработки.

## ✨ Реализовано

- Управление космическим кораблём
- Управление с клавиатуры
- Появление астероидов
- Движение астероидов
- Система очков
- Отображение счёта на экране

## 🕹 Управление

```text
W / ↑ — движение вверх
S / ↓ — движение вниз
A / ← — движение влево
D / → — движение вправо
```
