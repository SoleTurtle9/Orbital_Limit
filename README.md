# 🚀 Orbital Limit

**Orbital Limit** — небольшая 2D космическая игра, разработанная на Unity.

Игрок управляет космическим кораблём, уничтожает астероиды, набирает очки, следит за запасом здоровья и старается продержаться как можно дольше в условиях постоянно растущей сложности.

## 🎮 Текущая версия

## 🕹 Управление

```text
W / ↑ — движение вверх
S / ↓ — движение вниз
A / ← — движение влево
D / → — движение вправо
SPACE — выстрел
ESC — пауза
```

## 🌊 Система волн

```text
Игра начинается с волны 1.
Новая волна начинается каждые 20 секунд.
Интервал появления астероидов уменьшается на 0,1 секунды с каждой волной.
Минимальный интервал появления астероидов: 0,9 секунды.
После перезапуска игры здоровье и номер волны сбрасываются.
```

## ☄️ Типы астероидов

```text
Обычный астероид:
- появляется с первой волны;
- имеет базовую скорость, размер, урон и награду.

Быстрый астероид:
- появляется с 3 волны;
- меньше обычного;
- движется заметно быстрее;
- имеет 1 HP;
- наносит 15 HP урона;
- даёт 2 очка.

Тяжёлый астероид:
- появляется с 5 волны;
- крупнее обычного;
- требует несколько попаданий для уничтожения;
- наносит повышенный урон;
- даёт больше очков.
```

## 🎁 Бонусы

```text
Бонус здоровья:
- восстанавливает часть HP;
- не позволяет превысить максимум 100 HP.

Бонус ускоренной стрельбы:
- временно уменьшает задержку между выстрелами;
- после окончания эффекта обычная скорость стрельбы возвращается.
```
