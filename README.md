# 🚀 Orbital Limit

**Orbital Limit** — небольшая 2D космическая игра, разработанная на Unity.

Игрок управляет космическим кораблём, уничтожает астероиды, набирает очки, следит за запасом здоровья и старается продержаться как можно дольше в условиях постоянно растущей сложности.

## 🎮 Текущая версия

**v0.1.3 — Health and Wave Systems**

Проект находится на ранней стадии разработки.

## ✨ Реализовано

- Управление космическим кораблём
- Физическое движение и поворот корабля
- Управление с клавиатуры: WASD и стрелки
- Стрельба лазером
- Появление астероидов
- Движение астероидов
- Вращение астероидов
- Уничтожение астероидов выстрелами
- Система очков
- Отображение счёта на экране
- Система здоровья игрока на 100 HP
- Получение урона при столкновении с астероидами
- Отображение здоровья в интерфейсе
- Экран Game Over
- Перезапуск игры после проигрыша
- Система волн
- Отображение текущей волны в интерфейсе
- Новая волна каждые 20 секунд
- Постепенное увеличение сложности по волнам
- Движущийся звёздный фон
- Визуальный эффект попадания
- Звуки лазера, попадания и Game Over
- Централизованный AudioManager

## 🕹 Управление

```text
W / ↑ — движение вверх
S / ↓ — движение вниз
A / ← — движение влево
D / → — движение вправо
SPACE — выстрел
```

## 🌊 Система волн

```text
Игра начинается с волны 1.
Новая волна начинается каждые 20 секунд.
Интервал появления астероидов уменьшается на 0,1 секунды с каждой волной.
Минимальный интервал появления астероидов: 0,9 секунды.
После перезапуска игры здоровье и номер волны сбрасываются.
```
