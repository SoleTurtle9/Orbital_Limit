# Orbital Limit — проверка исправлений

Дата: 2026-11-08. Unity: 6000.6.6f1. Сцена: `Assets/Scenes/Game.unity`.
Проверка выполнена через Unity MCP и Unity Test Runner с разрешённым запуском Play Mode.

## Исправления

| Файл / объект | Причина и результат |
| --- | --- |
| `Assets/Prefabs/Laser.prefab`, `Assets/Scripts/Bullet.cs`, `Assets/Scripts/PlayerController.cs`; Ship / FirePoint | Лазер создавался внутри верхнего коллайдера Ship и имел твёрдый коллайдер. Коллайдер лазера переведён в trigger; при выстреле исключены контакты со всеми коллайдерами владельца. Снаряд больше не толкает корабль. |
| `Assets/Scripts/HealthPickup.cs`; аптечка | Успешный подбор блокирует повторные callbacks и отключает коллайдеры до эффектов и удаления. При полном HP аптечка остаётся. Уведомление показывает фактически восстановленные HP. |
| `Assets/Scripts/FireRatePickup.cs`; усиление стрельбы | Подбор фиксируется до применения усиления, звука и эффекта. Два коллайдера корабля не активируют бонус повторно. |
| `Assets/Scripts/Asteroid.cs`; астероиды | Состояние уничтожения устанавливается до эффектов и удаления. Повторное попадание не подтверждает повторное уничтожение; столкновение с двумя коллайдерами Ship наносит урон один раз. |
| `Assets/Scripts/Bullet.cs`; Laser | Первое попадание фиксируется до обработки цели, коллайдеры отключаются. Один снаряд не повреждает несколько перекрывающихся астероидов. |
| `Assets/Scripts/PlayerController.cs`; Ship | Стрельба блокируется при `Time.timeScale == 0`, смерти и Game Over, включая прямой вызов Shoot. |
| `Assets/Scripts/HUDController.cs`, `Assets/Scripts/GameManager.cs`; Canvas / GameplayHUD / GameOverPanel | Все игровые элементы HUD объединены под GameplayHUD и скрываются вместе, уведомления останавливаются. GameOverPanel остаётся видимым и выводится поверх остальных элементов Canvas. |
| `Assets/Scripts/HUDController.cs`; HealthFill | Полоска без sprite теперь изменяет ширину через anchors. Ранее Image.Filled без sprite не давал ожидаемого уменьшения полоски. |
| `Assets/Scripts/ScoreIconGraphic.cs`, `Assets/Scripts/HUDController.cs`; ScoreIcon | Звезда строится геометрией UI и не зависит от наличия символа U+2605 в LiberationSans. |
| `Packages/manifest.json`, `Packages/packages-lock.json` | Включён пакет Unity MCP; подключение к нужному проекту проверено. |

## Проверки

`Assets/Tests/PlayMode/GameplayRegressionTests.cs`: **22 теста Passed, 0 Failed, 0 Skipped**. Итог всей сборки тестов также Passed, включая завершение fixture.

- Контроль старого твёрдого коллайдера воспроизвёл сдвиг корабля `(0.24, 0.00)`; направление зависит от разрешения пересечения коллайдеров.
- Серия из 60 выстрелов исправленным лазером не сдвигает корабль; проверены trigger и исключения контактов с обоими коллайдерами Ship.
- Аптечка при двух контактах лечит один раз; при полном HP сохраняется; частичное лечение ограничено максимумом и показывает правильное число.
- Усиление создаёт один эффект, даёт интервал 0.12 с на 6 с и возвращает 0.35 с.
- Столкновение тяжёлого астероида с Ship наносит 35 урона один раз.
- Несколько снарядов при уничтожении тяжёлого астероида дают ровно 3 очка; один снаряд повреждает только одну из перекрывающихся целей.
- Пауза блокирует стрельбу, продолжение разрешает её. Game Over скрывает весь HUD и блокирует стрельбу. Перезапуск восстанавливает 100 HP, 0 очков и волну 1.
- При 50 HP полоса имеет половину ширины. Предупреждение ScoreIcon о U+2605 не возникло.
- Проверены интервалы волн 1, 3, 5, 12, 100 и появление быстрых/тяжёлых астероидов с волн 3/5.
- Ссылки на оба бонуса, AudioSource и четыре клипа AudioManager назначены.

Дополнительно: валидатор Game не нашёл отсутствующих скриптов или сломанных префабов. Проверены 192 сериализованные ссылки объектов сцены и префабов в `Assets/Prefabs`: потерянных ссылок и скриптов нет. Это проверка существующих назначений; намеренно пустые необязательные поля не считаются ошибкой.

Компиляция завершена успешно. После прогона ошибок игры в Console нет. Осталось предупреждение Unity MCP `WebSocket is not initialised` при перезагрузке домена; последующие запросы MCP выполняются успешно. Console вручную не очищалась. Редактор возвращён в Edit Mode, активна Game.

Тесты временно отключают ввод игрока и случайные спавнеры, создают реальные префабы и проверяют физические столкновения. Звуки во время тестов приглушены: назначение клипов проверено автоматически, качество и слышимость требуют прослушивания. Рекорд PlayerPrefs восстанавливается после набора тестов.

## Оставшиеся замечания по приоритету

Новых критических проблем в проверенных сценариях не обнаружено.

Средние:

1. `Assets/Scripts/MainMenuController.cs`, `Assets/Scripts/PauseMenuController.cs`, `Assets/Scripts/AudioManager.cs`: ползунок музыки сохраняет MusicVolume, но в скриптах проекта нет потребителя этой настройки. AudioManager управляет эффектами через SfxVolume. Музыкальная подсистема требует отдельного подключения.
2. `Assets/Scripts/Asteroid.cs`, `CHANGELOG.md`: скорость астероидов продолжает расти от очков, хотя changelog 0.1.3 говорит о переходе сложности на волны. Интервал спавна зависит от волн. Это расхождение документации и баланса; поведение сохранено.

Низкие:

1. `Assets/Scripts/Asteroid.cs`: Start перезаписывает сериализованный rotationSpeed случайным значением 30–90, поэтому Inspector не определяет итоговую скорость вращения.
2. `Assets/Scripts/PlayerController.cs`, `Assets/Scripts/HUDController.cs`: границы движения заданы фиксированными координатами центра корабля, размеры HUD — фиксированными величинами. Нужна визуальная проверка краёв экрана, поворотов и интерфейса при разных разрешениях.

## Ручная проверка перед слиянием

1. Зажать Space, одновременно двигаться и вращаться; проверить обычную и усиленную стрельбу у краёв экрана.
2. Прослушать лазер, попадание, подбор бонуса и Game Over, проверить ползунок звуков.
3. Проверить нажатия Escape, кнопок продолжения/перезапуска/выхода в меню и интерфейс на целевых разрешениях.
4. Провести длинную игровую сессию с несколькими волнами и наблюдать Console.

Изменения предназначены для отдельной ветки фиксов. Слияние в main не выполняется.
