# Отзывы игроков — Orbital Limit

Спасибо, что играете в Orbital Limit!

## Куда отправить отзыв

- **Впечатления и обсуждения:** [GitHub Discussions](https://github.com/SoleTurtle9/Orbital_Limit/discussions) (после включения владельцем репозитория).
- **Ошибка в игре:** [форма Bug Report](https://github.com/SoleTurtle9/Orbital_Limit/issues/new/choose).
- **Предложение механики:** [форма Feature Request](https://github.com/SoleTurtle9/Orbital_Limit/issues/new/choose).
- **Структурированный отзыв с оценкой 1–5:** [форма Player Feedback](https://github.com/SoleTurtle9/Orbital_Limit/issues/new/choose).

Указывайте версию игры (например, v0.1.5). Для ошибок добавляйте шаги воспроизведения и, по возможности, скриншот. Не публикуйте пароли, токены или личные данные.

## Настройка для владельца

1. В Settings → General → Features включите **Issues** и **Discussions**.
2. В Discussions создайте категории **Отзывы игроков**, **Идеи и предложения**, **Вопросы**.
3. После слияния PR проверьте три формы в Issues → New issue.
4. Добавьте ссылку на этот документ и Discussions в README и описание релиза Windows.
5. В Watch → Custom включите уведомления для Issues и Discussions.

Формы на GitHub требуют входа в GitHub. Для игроков без аккаунта потребуется отдельный внешний канал обратной связи.
