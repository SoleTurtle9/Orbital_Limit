# Changelog

Все заметные изменения в проекте Orbital Limit.

## [0.1.1] — 2026-09-29

### Added

* Управление космическим кораблём с помощью WASD и стрелок.
* Спавн астероидов.
* Движение астероидов.
* Система столкновений.
* Система очков.
* Отображение текущего счёта.
* Экран Game Over.
* Отображение итогового счёта после проигрыша.
* Кнопка PLAY AGAIN для перезапуска игры.

### Fixed

* Исправлена обработка столкновения корабля с астероидом.
* Исправлена остановка игры после Game Over.
* Исправлен перезапуск игровой сцены.
* Исправлено отображение счёта после перезапуска.

### Technical

* Добавлен отдельный GameManager для управления состоянием игры.
* Логика счёта отделена от логики Game Over.
* Подготовлена структура проекта для дальнейшего развития.
